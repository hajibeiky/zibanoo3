# سامانه هوشمند «زیبانو» (ZibaNo)
### پلتفرم یکپارچه جستجو، مقایسه و رزرو آنلاین آرایشگاه‌های زنانه و مردانه و خدمات زیبایی در محل
> **شعار:** «انتخاب آگاهانه، رزرو آسان»  
> **پروژه درس تجارت الکترونیکی — فاز اول (پرونده تحلیلی کسب‌وکار + MVP قابل‌آزمایش)**  
> **شهر پایلوت فاز اول:** یزد

---

## ۱. معرفی اجمالی پروژه
زیبانو سامانه‌ای نوین برای برطرف کردن چالش‌های سنتی انتخاب آرایشگاه و نوبت‌دهی است. در شیوه فعلی، کاربران با پراکندگی شدید اطلاعات در اینستاگرام، عدم شفافیت قیمت‌ها، اتلاف زمان بیش از ۲ ساعت برای مقایسه و تماس‌های تلفنی متعدد، و فقدان بستری امن برای ارائه خدمات زیبایی در محل (ویژه بیماران، سالمندان و افراد دارای محدودیت حرکتی) مواجه هستند.

زیبانو این فرآیند فرسایشی را به یک جریان هوشمند **۹ دقیقه‌ای** تبدیل می‌کند.

---

## ۲. ساختار پروژه و بخش‌های کلیدی فاز اول

### بخش اول: پرونده تحلیلی کسب‌وکار (Business Analysis Dossier)
مستندات دانشگاهی و تحلیلی کامل شامل ۶ فصل مدون:
1. **تبیین مسئله و اصطکاک‌های موجود:** تشریح ۵ اصطکاک بنیادی بازار سنتی و استنتاج نتیجه مسئله.
2. **ارزیابی ایده با هشت پرسش کلیدی:** تحلیل نیاز بازار، ارزش‌آفرینی دوطرفه، دسته‌بندی ترکیبی (Combined Idea)، مقیاس‌پذیری پایلوت یزد، مدل درآمدی (کمیسیون و اشتراک)، اعتبارسنجی میدانی، مدیریت موانع عملیاتی و راهکارهای جایگزین سنتی.
3. **دسته‌بندی ایده و مرزبندی فرایندها:** تفکیک دقیق فرایندهای آنلاین (دیجیتال در نرم‌افزار) و فرایندهای فیزیکی و حضوری (خارج از سامانه).
4. **مدل مقایسه‌ای اتلاف زمان و هزینه:** نمودار و تحلیل مقایسه‌ای کاهش زمان انتخاب از ۱۲۰+ دقیقه به ۹ دقیقه (صرفه‌جویی بیش از ۱.۵ ساعت).
5. **گزارش اعتبارسنجی اولیه و مصاحبه‌ها:** نتایج مصاحبه نیمه‌ساختاریافته با ۳ مشتری و ۲ آرایشگر در شهر یزد در قالب کارت‌های نقل‌قول مستند.
6. **نقشه سفر مشتری (Customer Journey Map):** تشریح ۵ مرحله سفر از آگاهی تا ارزیابی خدمت و راهکارهای زیبانو برای هر مرحله.

---

### بخش دوم: محصول اولیه قابل‌آزمایش (MVP)
پیاده‌سازی سناریوی کامل قابل‌تست در شهر یزد:
- **دایرکتوری جامع سالن‌ها:** ۹ آرایشگاه منتخب زنانه، مردانه و مراکز سیار در محلات مختلف یزد (صفائیه، قاسم‌آباد، بلوار جمهوری، ملاصدرا، میدان آزادی و...).
- **موتور جستجو و فیلتر پیشرفته:** فیلتر بر اساس نام، نوع سالن (زنانه/مردانه)، محله، دسته‌بندی خدمت (کوتاهی، رنگ، فیشیال، ناخن، ریش) و سطح قیمت.
- **فیلتر اختصاصی خدمات در محل:** شناسایی و تفکیک سریع آرایشگرانی که خدمات بهداشتی و زیبایی را در منزل یا مراکز درمانی ارائه می‌دهند.
- **صفحه جزئیات و آلبوم سالن:** اطلاعات کامل، تعرفه شفاف خدمات به تومان، آلبوم نمونه‌کارها، تیم آرایشگران و نظرات مشتریان.
- **میز مقایسه چندگانه (Multi-Salon Comparison):** امکان انتخاب ۲ تا ۴ سالن و مقایسه ستونی قیمت پایه، خدمات در محل، ساعات کاری و رضایت مشتریان.
- **فرآیند رزرو آنلاین نوبت:** انتخاب تاریخ (تقویم شمسی)، ساعت، استایلیست، نوع خدمت (حضوری یا در منزل)، صدور کد رهگیری اختصاصی (`ZB-XXXXX`) و ذخیره در حافظه محلی مرورگر (LocalStorage).
- **بخش نوبت‌های من:** مشاهده فهرست نوبت‌های فعال، وضعیت یادآوری پیامکی و امکان لغو نوبت.
- **پیش‌نمایش پنل مدیریت آرایشگر:** تقویم زمان‌بندی روزانه، مدیریت و تأیید درخواست‌های رزرو ورودی و تنظیم تعرفه‌ها.
- **فرم ثبت‌نام سالن جدید:** فرآیند عضویت آرایشگران و سالن‌های زیبایی شهر یزد.
- **پیش‌نمایش شبیه‌ساز هوشمند چهره (قابلیت آینده):** نسخه ماک پیشنهادات تطبیقی فرم چهره (بیضی، گرد، مربعی، قلبی) با مدل‌های مو.

## ۳. فناوری‌ها و ابزارهای توسعه
- **زیرساخت فرانت‌اند:** React 19 + TypeScript
- **ابزار ساخت و بیلد:** Vite
- **استایل‌دهی:** Tailwind CSS v4 با پشتیبانی کامل از چینش راست‌چین (RTL)
- **فونت فارسی:** Vazirmatn
- **آیکون‌ها:** Lucide React
- **انیمیشن و جشن رزرو:** Canvas Confetti & Motion
- **پایداری داده‌ها:** LocalStorage (بدون وابستگی به دیتابیس خارجی جهت اجرای آسان و پایدار)

## ۴. راهنمای نصب و اجرای محلی (Local Setup)

### پیش‌نیازها
- نصب بودن [Node.js](https://nodejs.org) (نسخه ۱۸ یا بالاتر)
- پکیج منیجر `npm`

### مراحل اجرا:
۱. در ترمینال، وارد پوشه پروژه شوید:
```bash
cd zibano-app
```

۲. نصب وابستگی‌ها (در صورت نیاز):
```bash
npm install
```

۳. اجرای سرور توسعه:
```bash
npm run dev
```

۴. برنامه روی آدرس زیر در دسترس خواهد بود:
```
http://localhost:3000
```

۵. بیلد نهایی جهت استقرار در پروداکشن:
```bash
npm run build
```

## ۵. سناریوی آزمایشی پیشنهادی برای ارزیابی (User Testing Scenario)
برای آزمودن کامل کارکرد سایت، مراحل زیر را طی فرمایید:
1. در صفحه اصلی، روی **«مشاهده پرونده تحلیلی کسب‌وکار»** کلیک کرده و ۶ فصل تحلیلی و نمودار مقایسه زمان را بررسی نمایید.
2. روی دکمه **«ورود به نسخه اولیه سامانه (MVP)»** کلیک کنید.
3. در کادر جستجو، عبارت `کوتاهی` یا `صفائیه` را جستجو کنید.
4. دکمه فیلتر **«فقط آرایشگاه‌های ارائه‌دهنده خدمات در محل»** را فعال کنید تا سالن‌های دارای خدمت منزل مانند *«مرکز تخصصی باران»* فیلتر شوند.
5. برای دو یا سه سالن دکمه **«افزودن به لیست مقایسه»** را بزنید و سپس از نوار شناور پایین، دکمه **«مشاهده جدول مقایسه»** را باز کنید.
6. یکی از سالن‌ها را انتخاب کرده و روی **«رزرو آنلاین نوبت»** کلیک کنید؛ خدمت، تاریخ و ساعت را انتخاب کرده و نام خود را وارد و ثبت کنید.
7. کد رهگیری صادرشده را مشاهده کرده و سپس با باز کردن پنجره **«نوبت‌های من»** از منوی بالا، نوبت ثبت‌شده را مشاهده یا لغو کنید.
8. از نوار بالای صفحه، **«پیش‌نمایش پنل آرایشگر»** را باز کنید تا نحوه مدیریت و پذیرش نوبت‌ها از سمت سالن‌دار را تجربه نمایید.
9. با کلیک بر روی دکمه **«ثبت‌نام آرایشگر»**، فرم عضویت سالن جدید را آزمایش کنید.
